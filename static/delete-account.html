Cara Meminta Penghapusan Data atau Akun Lengkap

Pengguna aplikasi ZiRa Finance memiliki hak penuh untuk meminta penghapusan akun secara menyeluruh ATAU meminta penghapusan data tertentu (seperti riwayat mutasi transaksi tertentu, daftar dompet tertentu, atau log notifikasi) tanpa harus menghapus akun pengguna:

1
Metode 1: Hapus Data Mandiri Langsung dari Aplikasi (Instan) Anda dapat menghapus data tertentu secara mandiri kapan saja:
  • • Hapus Transaksi: Buka tab Riwayat ➔ Tap transaksi ➔ Pilih Hapus Transaksi.
  • • Hapus Dompet: Buka menu Pengaturan ➔ Kelola Dompet ➔ Pilih Hapus Dompet.
  • • Cabut Sesi: Buka menu Pengaturan ➔ Sesi Perangkat Aktif ➔ Pilih Hapus Sesi.
2
Metode 2: Kirim Permintaan Penghapusan via Email Pengembang Kirimkan email permohonan ke zidzdev@gmail.com dengan subjek "Permintaan Hapus Data / Akun ZiRa Finance". Tuliskan data apa saja yang ingin dihapus (misal: seluruh mutasi bulan tertentu atau hapus total akun).
📊
Jenis Data yang Dihapus & Disimpan

Berikut adalah rincian perlakuan data saat permohonan penghapusan Anda diproses:

Kategori Data Status Penghapusan Keterangan Retensi
Profil Pengguna
Username, Display Name, Email, Google OAuth ID		 Dihapus Permanen Dihapus total dari database dalam waktu maksimal 24 jam.
Catatan Finansial & Transaksi
Riwayat pemasukan, pengeluaran, saldo, transfer		 Dihapus Permanen Seluruh mutasi keuangan dihapus dan tidak dapat dipulihkan.
Daftar Rekening & Dompet
Nama dompet bank, e-wallet, konfigurasi switch		 Dihapus Permanen Seluruh data dompet dihapus seketika.
Token Sesi & Bot Telegram
Bearer token, Telegram ID pairing, log notifikasi		 Dihapus Permanen Seluruh sesi dicabut dan log dihapus total.
Data yang Disimpan Tambahan Tidak Ada (0%) Kami tidak menyimpan cadangan data apa pun setelah akun/data dihapus.
⏳
Periode Retensi Data

Setelah permohonan penghapusan akun/data diverifikasi oleh tim pengembang:

• Waktu Proses: Seluruh data yang diminta akan dihapus secara permanen dari server aktif dalam kurun waktu maksimal 24–48 jam.

• Sifat Penghapusan: Proses penghapusan bersifat permanen dan tidak dapat dibatalkan atau dipulihkan kembali.
